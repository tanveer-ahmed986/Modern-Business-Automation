WHAT'S IN THIS RELEASE
================================================================================

This release packages the full Phase 1-4 system overhaul (see
specs/system-overhaul/plan.md and history/prompts/system-overhaul/ for the
full record) plus a live-use POS bug fix:

1. Backend stability, data-correctness, and security/licensing hardening
   - DB transaction integrity for stock/financial operations
   - Business-local-day time handling, stock ledger service
   - License/auth/RBAC hardening

2. Professional UI overhaul
   - Themeable app shell (TopBar, collapsible Sidebar, ErrorBoundary)
   - Shared DataTable, RHF+zod product form, dashboard trend/payment charts
   - Forced-password-change flow, reworked POS (cash-tendered/change-due
     calculator, keyboard shortcuts), CSV export on sales history

3. CRITICAL: Complete Sale button could stay disabled with items in cart
   Problem:
   - The "Cash Received" field defaulted to empty, which the checkout
     guard treated as PKR 0 received - always less than the total - so
     "Complete Sale" stayed disabled until the cashier typed in an exact
     or larger cash amount.
   Fix:
   - An empty "Cash Received" field no longer blocks checkout. It only
     blocks when the cashier has typed an amount that's actually short
     of the total.
   Files Modified:
   - frontend/src/features/billing/BillingPage.tsx

4. NEW: Hold Sale / Resume Sale
   - A cashier can now park an in-progress cart ("Hold Sale") to start a
     new sale for another customer, then resume the parked cart later
     ("Held Sales" dialog: Resume / Delete). Held sales persist across a
     page refresh.
   Files Modified:
   - frontend/src/features/billing/BillingPage.tsx
   - frontend/src/features/billing/useCalculator.ts

VERSION STRINGS NORMALIZED
================================================================================

The running app previously reported three different, inconsistent version

report "2.0.8" to match the installer:

  - backend/src/api/version.py (/version endpoint)
