PROBLEM IDENTIFIED
================================================================================

When MBAS v2.0.5 (or earlier) starts, a CMD console window appears and remains
visible. This is unprofessional and can confuse users.

ROOT CAUSE
================================================================================

The tray application (mbas_tray.py) was using python.exe to launch the uvicorn
server. On Windows, python.exe ALWAYS shows a console window, even with the
CREATE_NO_WINDOW flag.

THE SOLUTION
================================================================================

Changed the launcher to use pythonw.exe instead of python.exe.

pythonw.exe is a Windows-specific Python executable designed for GUI applications.
It runs without ANY console window - perfect for background services like MBAS.

TECHNICAL CHANGES
================================================================================

Files Modified:
  1. scripts/mbas_tray.py
  2. deployment/build_installer/scripts/mbas_tray.py

Changes Made:
  Line ~221: self.python_exe → self.pythonw_exe (uvicorn server)
  Line ~234: self.python_exe → self.pythonw_exe (watchdog process)

Code Changes:
  BEFORE: [self.python_exe, "-m", "uvicorn", ...]
  AFTER:  [self.pythonw_exe, "-m", "uvicorn", ...]

Impact:
  ✓ Server runs completely hidden
  ✓ No CMD window visible
  ✓ No performance impact
  ✓ All functionality preserved
  ✓ Logs still work normally

FREQUENTLY ASKED QUESTIONS
================================================================================

Q: Will this break existing installations?
A: No. The fix only changes HOW the server starts, not WHAT it does.
   All functionality, data, and settings are preserved.

Q: Do users need to uninstall first?
A: No. Users can either:
   - Reinstall over existing installation (preserves data)
   - Use FIX_HIDDEN_SERVER.bat for quick update

Q: Will the server still run in the background?
A: Yes! The server runs the same way, just without the visible window.

Q: Can I still see logs?
A: Yes! Logs are still written to C:\ProgramData\MBAS\logs\mbas_tray.log

Q: What if pythonw.exe doesn't exist?
A: The code has a fallback - if pythonw.exe is missing, it uses python.exe.
   pythonw.exe is included in all standard Python installations.

Q: Will performance be affected?
A: No. pythonw.exe and python.exe have identical performance.
   The only difference is console window visibility.

Q: Is this compatible with Windows 11?
A: Yes! This fix works on all Windows 10 and Windows 11 versions.

Q: Can I revert to the old version?
A: Yes. Use the backup created by FIX_HIDDEN_SERVER.bat, or reinstall v2.0.5.
