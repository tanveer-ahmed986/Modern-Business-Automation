MBAS v2.1.0 PWA - Mobile & Tablet Testing Guide
How to Test MBAS on Smartphones and Tablets
================================================================================

OVERVIEW

MBAS v2.1.0 is a Progressive Web App (PWA) that works on:
  ✓ Android phones and tablets (Android 8.0+)
  ✓ iOS phones and tablets (iOS 14+)
  ✓ Any device with a modern web browser
  ✓ Works over WiFi - no internet required!

================================================================================

STEP 1: SETUP WIFI ACCESS

1.1. Find Your Computer's IP Address
   - On Windows PC running MBAS:
     - Open Command Prompt
     - Type: ipconfig
     - Look for "IPv4 Address" under your WiFi adapter
     - Example: 192.168.1.100
     - Write this down!

1.2. Start MBAS Server
   - Double-click START_MBAS_PWA.bat
   - Wait for "Uvicorn running" message
   - Server binds to 0.0.0.0:8000 (accessible on WiFi)

1.3. Check Firewall
   - Windows Firewall may block access
   - If mobile can't connect:
     → Control Panel → Windows Defender Firewall
     → Allow an app → Python → Check both Private and Public

================================================================================

STEP 2: ANDROID TESTING

2.1. Requirements
   - Android 8.0 or higher
   - Chrome browser (pre-installed on most phones)
   - Connected to same WiFi as PC

2.2. Access MBAS
   - Open Chrome browser
   - Type in address bar: http://YOUR-IP:8000
     (Replace YOUR-IP with the IP from Step 1.1)
   - Example: http://192.168.1.100:8000
   - MBAS should load (might take 5-10 seconds first time)

2.3. Install as App
   - Tap menu (⋮) in Chrome
   - Select "Add to Home screen"
   - Tap "Add"
   - Icon appears on your home screen
   - Tap icon to open MBAS as a standalone app

2.4. Test Features
   □ Login (admin/admin123)
   □ Navigate: Dashboard → Inventory → Billing
   □ Add a product
   □ Create a sale
   □ Search for items
   □ All buttons and forms work
   □ Scrolling is smooth
   □ No lag when switching sections

2.5. Test Offline Mode
   - Open MBAS app
   - Turn off WiFi on phone
   - Close the app
   - Reopen MBAS from home screen
   - Should still work! (shows offline banner)
   - Turn WiFi back on → "Back online!" message

================================================================================

STEP 3: iOS TESTING (iPhone/iPad)

3.1. Requirements
   - iOS 14 or higher
   - Safari browser (default on iPhone/iPad)
   - Connected to same WiFi as PC

3.2. Access MBAS
   - Open Safari browser
   - Type in address bar: http://YOUR-IP:8000
     (Use IP from Step 1.1)
   - MBAS loads in Safari

3.3. Install as App
   - Tap Share button (square with arrow pointing up)
   - Scroll down
   - Tap "Add to Home Screen"
   - Tap "Add" (top right)
   - Icon appears on home screen
   - Tap icon to open MBAS

3.4. Test Features
   □ Login works
   □ All pages load
   □ Touch gestures work
   □ Forms are usable
   □ Virtual keyboard doesn't block content

3.5. Offline Mode
   Note: iOS has stricter PWA requirements
   - Full offline mode may require HTTPS
   - For beta testing, keep WiFi connected

COMMON ISSUES & SOLUTIONS

Problem: Can't connect from mobile
Solutions:
  1. Verify both devices on same WiFi network
  2. Check IP address is correct (ipconfig)
  3. Ping from mobile (use Network Analyzer app)
  4. Disable Windows Firewall temporarily to test
  5. Try http://192.168.1.X:8000 (replace X with your PC's IP)

Problem: Slow loading on mobile
Solutions:
  1. First load is always slower (downloading assets)
  2. Subsequent loads use cache (should be instant)
  3. Check WiFi signal strength
  4. Close other apps using network

Problem: Can't install on home screen
Solutions:
  - Android: Use Chrome browser (not other browsers)
  - iOS: Use Safari browser (not Chrome)
  - Make sure you're accessing via IP, not localhost

Problem: Offline mode doesn't work
Solutions:
  - Must visit while online first (to cache assets)
  - Service Worker needs to register (check first visit)
  - iOS has limited offline support without HTTPS

Problem: Keyboard blocks input fields on mobile
Solutions:
  - Scroll the page to bring field into view
  - Rotate phone to landscape mode for more space
  - Tap outside keyboard, then back on field
