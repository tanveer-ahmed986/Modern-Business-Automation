================================================================================
TROUBLESHOOTING GUIDE
================================================================================

If installer fails:
  - Check Python installation
  - Run as Administrator
  - Disable antivirus temporarily
  - Check disk space (500 MB required)
  - Review install_log.txt

If CMD window still appears:
  - Verify using v2.0.6 installer
  - Check C:\Program Files\MBAS\scripts\mbas_tray.py
  - Look for "pythonw.exe" in line 220-230
  - Check pythonw.exe exists in venv
  - Reinstall if needed

If server won't start:
  - Check logs: C:\ProgramData\MBAS\logs\mbas_tray.log
  - Verify port 8000 not in use
  - Check firewall settings
  - Verify Python packages installed
  - Try START_MBAS_DIRECT.bat for debugging
