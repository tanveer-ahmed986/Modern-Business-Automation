GETTING STARTED

1. START THE SERVER
   - Double-click: START_MBAS_PWA.bat
   - Wait for "Uvicorn running on http://0.0.0.0:8000" message

2. OPEN IN BROWSER
   - Desktop: http://localhost:8000
   - Mobile/Tablet: http://YOUR-IP:8000
     (Find IP with 'ipconfig' command)

3. LOGIN
   - Username: admin
   - Password: admin123

4. INSTALL AS PWA (Optional)
   - Chrome/Edge: Click install button (⊕) in address bar
   - The app will install to your desktop/start menu

TROUBLESHOOTING

Problem: "Cannot connect to server"
Solution:
  - Make sure START_MBAS_PWA.bat is running
  - Check Windows Firewall isn't blocking port 8000
  - Try http://127.0.0.1:8000 instead

Problem: Server won't start
Solution:
  - Check Python is installed: python --version
  - Reinstall dependencies: Run INSTALL_PWA.bat
  - Check port 8000 isn't in use: netstat -ano | findstr :8000

Problem: Old MBAS version conflicts
Solution:
  - Stop old MBAS: STOP_MBAS.bat (or Task Manager → End python.exe)
  - Delete old database: C:\ProgramData\MBAS\data\mbas_database.db
  - Restart: START_MBAS_PWA.bat
