INSTALLATION INSTRUCTIONS
================================================================================

REQUIREMENTS:
- Windows 7 SP1 / 10 / 11
- Python 3.10, 3.11, or 3.12 (REQUIRED)
- 2GB RAM minimum
- 100MB free disk space

STEPS:

1. Install Python (if not already installed)
   Download from: https://www.python.org/downloads/
   ⚠️ IMPORTANT: Check "Add Python to PATH" during installation!

2. Run MBAS_v2.1.0_PWA_Professional_Setup.exe
   - Follow installation wizard
   - Choose install location (default: C:\Program Files\MBAS)
   - Select shortcuts
   - Click Install

3. Wait for installation (1-2 minutes)
   - Files extracted
   - Dependencies installed (silent)
   - Database initialized
   - NO CMD windows will appear!

4. Launch MBAS
   - Check "Launch MBAS now" at end of installation
   - OR double-click "MBAS v2.1.0" desktop icon
   - Browser opens automatically
   - Login: admin / admin123

5. Verify License
   - Login to MBAS
   - Go to Settings (gear icon)
   - Check License Information
   - Should show: STANDARD tier, ACTIVE status, PERPETUAL type

UPGRADING FROM v2.0.5 OR EARLIER
================================================================================

RECOMMENDED PROCESS:

1. Backup your data
   - Open current MBAS
   - Go to Settings → Backup
   - Save backup file to safe location

2. Uninstall old version
   - Control Panel → Programs
   - Find "MBAS" (old version)
   - Click Uninstall

3. Install new version
   - Run MBAS_v2.1.0_PWA_Professional_Setup.exe
   - Follow installation wizard

4. Restore your data (if needed)
   - Open new MBAS
   - Go to Settings → Restore
   - Select your backup file

NOTE: Database format is compatible, but always backup first!

================================================================================
TROUBLESHOOTING
================================================================================

PROBLEM: Installer says "Python not installed"
SOLUTION: Install Python from python.org
         Make sure to check "Add Python to PATH"

PROBLEM: Server won't start
SOLUTION: Check if port 8000 is available
         Stop any existing MBAS instances
         Restart computer if needed

PROBLEM: Browser doesn't open automatically
SOLUTION: Manually open browser
         Go to: http://localhost:8000

PROBLEM: License shows "Basic" not "Standard"
SOLUTION: This should NOT happen with this installer
         If it does, contact support immediately

PROBLEM: Performance is slow
SOLUTION: Close other applications
         Check system has 2GB+ RAM
         Try with fewer than 100 products initially

For more help: support@zttechnologies.org
