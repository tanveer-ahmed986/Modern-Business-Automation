INSTALLATION INSTRUCTIONS
================================================================================

Fresh Installation:
-------------------
1. Ensure Python 3.11 or 3.12 is installed
2. Run MBAS_Professional_Setup_v2.0.6_ZT_Technologies.exe
3. Follow the installation wizard
4. Wait for dependency installation (2-5 minutes)
5. Launch MBAS when prompted
6. Login with: admin / admin123
7. IMPORTANT: Change password after first login

Upgrade from v2.0.5 or earlier:
-------------------------------
Option A - Reinstall (Recommended):
1. Uninstall previous version
2. Install v2.0.6
3. Data is preserved in C:\ProgramData\MBAS\

Option B - Quick Fix:
1. Extract the package
2. Run FIX_HIDDEN_SERVER.bat as Administrator
3. Restart MBAS

VERIFICATION STEPS
================================================================================

After installation, verify:

□ MBAS icon appears on desktop
□ Start Menu entry created
□ Launch MBAS (no CMD window should appear)
□ System tray icon appears within 10 seconds
□ Tray icon turns green (server running)
□ Browser opens to http://localhost:8000
□ Login page loads
□ Can login with admin/admin123
□ Dashboard displays correctly
□ All modules accessible
□ Can create/edit records
□ Reports generate successfully

Troubleshooting:
----------------
If issues occur:
1. Check logs: C:\ProgramData\MBAS\logs\mbas_tray.log
2. Check firewall: Port 8000 allowed for localhost
3. Verify Python: Run "python --version" in CMD
4. Restart Windows
5. Contact support: zttechnologies12@gmail.com
