WHAT'S NEW IN VERSION 2.0.6
================================================================================

MAJOR FIX: Hidden Server Background Execution
----------------------------------------------
The server now runs completely hidden in the background with no visible
console window. This provides a much more professional user experience.

Technical Details:
  - Changed server launcher to use pythonw.exe instead of python.exe
  - pythonw.exe is the Windows GUI version that runs without a console
  - Applied to both uvicorn server and watchdog processes
  - No impact on functionality, only on visibility

User Experience Improvements:
  ✓ No CMD window appears when starting MBAS
  ✓ Server runs silently in background
  ✓ Clean, professional appearance
  ✓ System tray icon remains fully functional
  ✓ All features work exactly as before

UPGRADE OPTIONS
================================================================================

Option 1: Full Reinstall (Recommended)
---------------------------------------
1. Uninstall MBAS v2.0.5 (or earlier)
2. Install MBAS v2.0.6
3. Your data is preserved in C:\ProgramData\MBAS\

Option 2: Quick Fix (For Existing Installations)
-------------------------------------------------
1. Download the v2.0.6 package
2. Run FIX_HIDDEN_SERVER.bat as Administrator
3. Restart MBAS
4. Verify no CMD window appears
