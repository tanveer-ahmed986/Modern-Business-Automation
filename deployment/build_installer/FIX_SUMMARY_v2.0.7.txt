ISSUES FIXED
================================================================================

1. CRITICAL: Categories Not Created During Installation
   -------------------------------------------------------
   Problem:
   - Fresh installations failed to create product categories
   - Users saw empty category dropdown when adding products
   - Categories table was completely empty in database

   Root Cause:
   - The bootstrap script (backend/src/scripts/init_db.py) only created
     Settings and Admin user, but did NOT create sample categories
   - The full init script (backend/init_database.py) creates categories
     but was never called during installation

   Fix Applied:
   - Updated backend/src/scripts/init_db.py to create 4 sample categories:
     * Electronics
     * Groceries
     * Clothing
     * Stationery
   - Added category creation to backend/src/main.py startup routine
   - Categories now created both during installation AND on first server start

   Files Modified:
   - backend/src/scripts/init_db.py (lines 10, 90-106)
   - backend/src/main.py (lines 84, 119-131)

2. CRITICAL: CMD Window Flashing/Blinking
   ----------------------------------------
   Problem:
   - CMD window would briefly appear when server operations occurred
   - Unprofessional user experience
   - Occurred during watchdog auto-restart operations

   Root Cause:
   - Watchdog process used subprocess.run() without CREATE_NO_WINDOW flag
   - System commands (taskkill, netstat) were showing CMD windows
   - Watchdog restart didn't explicitly use pythonw.exe

   Fix Applied:
   - Added CREATE_NO_WINDOW flag to all subprocess calls in watchdog.py
   - Added STARTUPINFO with SW_HIDE to suppress console windows
   - Watchdog now explicitly finds and uses pythonw.exe for restarts
   - All taskkill and netstat commands now run completely hidden

   Files Modified:
   - backend/watchdog.py (lines 61-106, 108-139)

TECHNICAL DETAILS
================================================================================

Category Creation Flow:
-----------------------
Installation:
  1. Installer runs INSTALL_MBAS.bat
  2. INSTALL_MBAS.bat calls: backend/src/scripts/init_db.py::bootstrap()
  3. bootstrap() now creates categories if none exist

First Server Start:
  1. main.py lifespan() runs init_db()
  2. Ensures Settings, Admin user, AND categories exist
  3. Creates 4 sample categories if table is empty

This dual approach ensures categories are created even if:
- Installation bootstrap failed silently
- Database was manually deleted
- Upgrading from older version

CMD Window Suppression:
-----------------------
Windows process creation flags used:
  - subprocess.CREATE_NO_WINDOW (0x08000000)
  - startupinfo.dwFlags = STARTF_USESHOWWINDOW
  - startupinfo.wShowWindow = SW_HIDE (0)

Applied to:
  - taskkill commands (kill python/pythonw processes)
  - netstat commands (find processes on port 8000)
  - Backend server restart via uvicorn

Python executable selection:
  - If sys.executable is python.exe, look for pythonw.exe in same dir
  - Use pythonw.exe if found, fallback to python.exe
  - Ensures no console window even during auto-restarts
